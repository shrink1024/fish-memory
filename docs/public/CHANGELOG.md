# 版本说明

## 0.1.0-alpha.4（2026-10-09）

- 自动维护默认改为积累 3 轮助手回复再执行；设置页提供每 1、3、5、10、20 轮选项，并保留 1–20 轮的有效自定义值。待补记正文达到一批大小（默认 18,000 字符）时提前补记，也可随时手动立即补记。
- 等待积累时，未补记原文继续用于选材与正文上下文，历史窗口不提前省略。前置选材仍每轮执行，维护仍读取所属范围完整可写资料。本次减少重复调用频率，不承诺固定 token 或费用节省比例。
- 摘要与事件没有变化时，不再仅因轮数累计发起空整理；整理返回空修改也会保存已核对记录，刷新后不会重复处理同一范围。整理记录及失败重试计数与当前剧情的维护提交对应，回滚或重选早期候选后不会沿用失效记录；并发新增资料不会被旧整理请求标记为已核对。
- 修复手机经局域网 HTTP 访问时，浏览器缺少安全上下文专用接口导致建档失败的问题；内容核对与存档身份生成提供兼容处理。
- 预设偏好扫描改为设置页中的独立可选操作，旧聊天建立记忆无需先完成该扫描。
- 世界书分类和历史剧情扫描按批保存进度。失败、停止或刷新后，手动重试会核对后继续有效批次；原书、规则、偏好或范围变化时使不匹配进度失效，候选变化按有效剧情前缀回退。部分扫描不会提前替换正式动态资料，完整成功后再保存采用。
- 修复作者长度限制使原本过长但未改写的条目阻塞初始化或其他条目维护的问题；限制仍检查本次新写入的正文。
- 管理窗口改为固定非模态浮层，收起后留下可发现的“鱼忆”气泡，显示运行和待补记状态。支持拖动贴边、位置选单、键盘操作、视口与安全区适配；重新打开保留页签和编辑草稿。原顶部与扩展设置入口保留，输入区上方的独立状态块不再占位。

377 项程序测试、88 文件检查通过；隔离演示验证桌面及实际 416 / 320 像素窄屏的浮窗、收起重开、设置草稿保留、键盘与明暗模式，展开前后页面尺寸不变，气泡避开输入区。

本轮验证未调用真实模型，也未修改玩家存档；程序回归和隔离演示只核对流程与交互，不代表真实大存档耗时、长期记忆质量或物理手机兼容性验收。

## 0.1.0-alpha.3（2026-10-08）

- 世界书扫描、统合策略、历史补记和后台整理的默认等待上限改为每次请求 30 分钟，修复初始化历史批次仍沿用 90 秒的遗漏。前置选材与预设扫描默认 5 分钟。多批任务不设总时限。
- 设置页新增“辅助模型等待时间”，可分别选择两类上限，最长 24 小时，或选择“不限时（手动停止）”。不限时仅关闭鱼忆自身计时；原有停止、取消和迟到结果隔离继续生效。
- 保存后下一次请求立即使用新上限，当前请求沿用原值；兼容接口连接和本页密钥保留。设置保存失败时继续使用原上限。
- 自动升级旧版本保存的默认 90 秒／180 秒，保留已有自定义时长及新版明确保存的选择。非法时长在保存前拒绝。
- 333 项程序测试、80 文件检查通过；隔离演示中完成桌面／窄屏布局及等待选项保存验证。未调用真实模型，未验证几千楼实际处理耗时；延长等待不会突破模型上下文、酒馆代理或供应商自身限制。

## 0.1.0-alpha.2（2026-10-08）

- 修复初始化因模型重抄原文时漏字而整批失败的问题。正文由程序保留，模型只返回分类、简介和分段起点；无法准确定位的条目保留完整原文、暂时保护并标记“待核对”。原世界书不变。
- 初始化完成提示增加待核对数量。旧格式的完整分段仍可处理，分段模糊或混用格式不会自动扩大写权限。
- 扫描世界书与统合策略的默认等待上限调整为 180 秒；前置选材及其他辅助请求仍为 90 秒。超时、密钥无效和非 JSON 返回给出明确说明，停止后迟到结果不采用。
- 收发记录和请求统计现在包含分类、选材、策略及预设的响应校验失败，并保留模型原始返回供排查。“已接收”仍只表示收到响应，保存阶段的权限检查与持久化另行执行。
- 保留用户修订的 AIRP 共用开头与收尾文案；本轮只调整初始化的分类输出协议。更新鱼忆并刷新酒馆后生效；初始化失败的存档可点击“手动扫描 / 重试初始化”，无需删除聊天。
- 325 项程序测试、79 文件语法与入口检查通过，三次故障日志中的分类返回均通过离线回放；漏字条目原文完整保留并转为受保护、待核对。没有调用真实模型或修改玩家存档。

## 0.1.0-alpha.1 后续提示词调整（2026-10-08）

- 初始化、策略对齐、前置选材、后置维护和事件整理统一补充 AIRP 虚构语境及任务收束，区分角色的意图／行动与现实用户的请求。
- 前置明确只选择资料 ID，后置明确只记录已有剧情，并各补充一个独立编写的例子，减少将资料处理误解成执行角色行为、改写剧情或现实劝告的歧义。
- 本次 57 项相关程序回归、75 文件语法与入口检查通过；尚未进行真实模型的修改前后对照，不能据此认定误拒绝已经解决。通过扩展管理器更新鱼忆并刷新酒馆后，新提示词才会用于后续辅助请求。

## 0.1.0-alpha.1 候选（2026-10-08）

这是鱼忆首次独立公测的 alpha 候选，源码仓库为 [shrink1024/fish-memory](https://github.com/shrink1024/fish-memory)。许可证尚未确定，GitHub Release 与社区公测公告尚未发布。本轮已完成程序回归与下列隔离宿主检查，包括停用／卸载、本地Git安装／更新及成对备份回退。它们是合成样例的有限验收，不是跨模型或全部存档兼容认证。

### 本次候选的修复与整理

- 2026-10-08 后续调整：历史窗口默认开启，默认保留最近 12 轮完整对话，只在当次请求中省略已有有效记忆覆盖的更早原文。更新保留已保存的关闭选择；聊天记录不删除。
- 历史窗口改为当次请求过滤，不新增永久隐藏正文。在隔离酒馆核对最终请求：已覆盖的旧原文被省略、摘要保留，聊天文件没有新增持久隐藏。dev.11旧隐藏档在总开关关闭及分支载入时恢复自己的标记，保留外部工具的隐藏。
- 提供dev.11离线JSONL恢复页，多选文件后分别检查、下载副本；只恢复鱼忆标记，原文件不变，文件内容不上传。桌面、375像素手机视口、键盘下载与直接离线打开均已验证。
- 原生一次生成多个候选并删除候选后，按当前有效候选对齐记忆，避免同下标复用已删剧情。已通过原生多候选生成与删除的隔离宿主验证。dev.11中已经错记、且旧候选身份丢失的档无法自动推断修正，需备份后按当前剧情重新扫描。
- 对照初始化基准检测同名原书正文与元数据的新增、修改和删除，提示后暂停旧基准重置与自动维护；前置可选择原书发送或取消，备份后由玩家手动重新扫描。可选资料范围物品投递补充来源说明。这两项已有程序回归，不作全部卡与模板组合的宿主兼容承诺。
- 设置保存后回读核对，失败或生成期间仅排队时提示未确认并恢复本页先前设置；磁盘可能已写入，需在辅助生成结束或连接恢复后重试核对，不能视为磁盘也已回滚。
- 构建使用显式发行白名单，并在每次构建前清理目标目录；源码包与最小安装包分开，附文件清单和SHA-256校验和。旧开发记录、研究资料、截图、模型日志及本地存档不进入候选包。
- 玩家README、安装／更新／回退／退出说明、反馈模板与公测草稿独立整理，明确自动建档会产生额外调用，单独辅助连接刷新后失效，以及问题导出的隐私范围。

### 已有功能

角色主绑定世界书的存档内动态副本；新开场档自动建档与旧档手动分批扫描；前置选材、后置维护、故事脉络、人物、事件与可关闭的玩家物品清单；按档开关、停止与失败恢复；只读发送前预览、内存收发查看器与当前档问题导出。可选MVU只读字段协作，普通卡无需适配或安装MVU。

以上真实宿主均使用**本地合成响应，没有调用真实模型**。它们验证宿主流程、最终请求与保存结果，不能证明模型长期事实判断、召回或叙事质量。手机项为浏览器视口与触控模拟，未作物理手机验收。

本轮观察到：在发送前置阶段停止时，酒馆可能已经保留本轮用户消息，但不会继续生成新的助手正文；重发前应检查聊天。原生辅助请求的逻辑取消不保证供应商立即停止计费。

### 发布状态与支持边界

上述酒馆内Git安装与更新验收使用经过筛选的本地HTTP仓库，不代表已在酒馆内实测公网GitHub安装。公开源码仓库为 [shrink1024/fish-memory](https://github.com/shrink1024/fish-memory)，作者署名为 shrink1024；GitHub Release、社区公告和许可证仍分别待落实。

群聊、多客户端同时写同一档、复杂EJS主动读取、全部模型后端与第三方扩展组合未获完整支持。长期模型质量、真实MVU组合和大存档成本仍属后续实测／公测观察范围。当前schema为2，其他旧开发格式不自动迁移。详见 [兼容说明](../../COMPATIBILITY.md) 和 [更新与恢复](../../INSTALL.md)。
