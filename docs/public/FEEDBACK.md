发生后、刷新前，优先使用 **鱼形按钮 → 收发 → 实际记录 → 导出本次问题**。它提供当前档的鱼忆状态与相关记录；可选客户端注册的诊断也可能在包内。没有日志时，写出步骤、预期和实际结果也有价值。

日志只在当前页面内存保留，受容量上限约束，刷新后不能恢复。“导出全部”包含本页仍保留的其他聊天记录，不等同于当前档问题包。内容可能含私人剧情、预设、角色资料、提示词以及正文中自行写入的敏感信息；配置凭据过滤不等于匿名。上传前请自行检查、删去不愿提供的内容，勿公开API密钥、完整设置文件或整个酒馆数据目录。

报告延迟和费用时，请区分正文生成与辅助任务、初始化与普通一轮、成功与重试，并记录观察到的次数或耗时。停止等待不保证供应商停止计费。报告错记或漏选时，一项明确事实及其发生顺序比“感觉不聪明”更便于排查。
